First release of the Android home screen widget for the Tenda MF6 mobile modem.

## What it does

- **Widget** (3x1, resizes down to 2x1): signal strength, network type, modem
  battery, unread SMS, operator, data left or used, time of the last update.
  The refresh button spins while a poll runs.
- **Background polling** every 15, 30, 60 or 180 minutes, plus a notification
  when a new SMS arrives.
- **SMS screen**: message list, tap a message to read it in large type (this
  marks it read on the modem), pull down to reload, "Mark as read" for all.
- **Settings** are saved as you change them; widget background opacity is
  adjustable.

## Install

1. Download `tendamf6-1.0.apk` below and open it on the phone (Android 8.0 or
   newer). Allow installing from your browser or file manager if asked.
2. Open the app and enter the modem's address (`192.168.0.1` by default) and
   its web interface password.
3. Add the widget from the home screen's widget list.

The phone has to be connected to the modem's Wi-Fi; away from it the widget
keeps the last data and marks it with ⚠.

If you installed a build from Actions or one built locally, uninstall it
first: those are signed with a different key, so this release will not install
over them.
